# Welcome to Coding Corgi! 🐕

Hello and welcome! This is the first post on the **Coding Corgi** website, a personal space dedicated to sharing learning materials, insights, and experiences from the world of software development.

## What is Coding Corgi?

Coding Corgi is more than just a website — it's a mindset. Just like a corgi is small but mighty, friendly but focused, this project embodies an enthusiastic and determined approach to learning and teaching software development.

## What You'll Find Here

This website will feature:

- **Learning Materials**: Tutorials, guides, and explanations of software development concepts
- **LinkedIn Posts**: Content originally shared on LinkedIn, now collected and organized here
- **Real-World Insights**: Lessons learned from actual development projects
- **Best Practices**: Tips, tricks, and patterns for writing better code

## How to Add New Posts

If you're Evgeny (hi, that's me!), here's how to add new LinkedIn posts:

1. Create a new `.mdx` file in `src/content/posts/`
2. Add frontmatter with title, description, date, optional LinkedIn URL, and tags
3. Write your content in Markdown (with optional JSX components)
4. The post will automatically appear on the site!

Example frontmatter:
```yaml
---
title: "Your Post Title"
description: "A brief description"
publishedDate: 2026-05-02
linkedinUrl: "https://linkedin.com/posts/your-post-url"
tags: ["tag1", "tag2"]
---
```
