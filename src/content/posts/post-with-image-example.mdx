# How to Add Posts with Images

This is an example post demonstrating how to include images in your LinkedIn posts on the Coding Corgi website.

## Cover Images

Every post can have a **cover image** that appears:
- In the post card on the posts list page
- At the top of the full post page

To add a cover image, include it in your frontmatter:

```yaml
---
title: "Your Post Title"
coverImage: ./_images/your-image.jpg
coverImageAlt: "Description of the image"
---
```

## Inline Images in Content

You can also add images directly within your MDX content. Here's an example:

<Image 
  src={placeholderImage} 
  alt="Inline example image" 
  class="rounded-lg shadow-md my-6"
/>

To add inline images, import them at the top of your MDX file:

```jsx
import { Image } from 'astro:assets';
import myImage from './_images/my-image.jpg';

// Then use it in your content:
<Image src={myImage} alt="Description" class="rounded-lg" />
```

## Where to Store Images

Store all your images in: `src/content/posts/_images/`

This keeps your images organized alongside your posts.

## Supported Image Formats

- **JPG/JPEG** - Best for photos
- **PNG** - Best for screenshots and images with transparency
- **WebP** - Modern format, smaller file sizes
- **SVG** - Vector graphics (like the example above)

## Image Optimization

Astro automatically optimizes your images:
- Converts to modern formats (WebP)
- Generates multiple sizes for responsive images
- Lazy loads images for better performance
- Optimizes file sizes

Just add your images and Astro handles the rest!

## Example LinkedIn Post Workflow

1. Download your LinkedIn post image
2. Save it to `src/content/posts/_images/`
3. Create your MDX file with the image in frontmatter
4. Add any additional inline images as needed
5. Write your content

That's it! Your post will automatically show the image in cards and on the full page.
